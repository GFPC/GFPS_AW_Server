# aw-core

Core library for ActivityWatch: `Event`, schemas, `aw_datastore`, `aw_transform`, `aw_query`.

## Install

```bash
pip install -e .
```

Optional frozen deps: `pip install -r requirements.txt && pip install -e . --no-deps`

Dev: `pip install -r requirements-dev.txt` or `pip install -e ".[dev]"`.

## Logging

Set `LOG_LEVEL=debug` for verbose logs.
